# ADR 0002 — GPL-3.0-or-later

Status: accepted

## Context

Tauri, Rust crates used here, React, and Tailwind are MIT or Apache-2.0. The Ubuntu FFmpeg on the development VM is GPL because it is built with `--enable-gpl` and libx264. MLT's melt CLI is GPL. An LGPL FFmpeg build is also a legal way to obtain the executable.

## Decision

PulseCut is GPL-3.0-or-later. The license text is `LICENSE`. FFmpeg is an external program. This repository does not vendor FFmpeg, libx264, or MLT.

## Consequences

MIT and Apache-2.0 dependencies can be combined into a GPL-3.0 work. A later Windows installer that bundles a GPL FFmpeg build must ship that build's source and notices. An installer that only invokes a user-installed FFmpeg does not redistribute FFmpeg. Patent obligations for H.264 are not removed by the GPL. See `docs/LICENSE_AUDIT.md`.
