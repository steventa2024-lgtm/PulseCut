# ADR 0006 — Tauri 2 on Rust 1.99

Status: accepted

## Context

The preferred shell was Tauri 2. Rust 1.83 could not parse current crates (`edition2024` via `getrandom` 0.4). Tauri 2.12.3 declares rust-version 1.90. Tauri 2.11 with caret dependencies pulled a newer `tauri-build` that also needs 1.90. Tauri 3 alpha was not used.

## Decision

Pin Rust 1.99.0 in `rust-toolchain.toml`. Pin `tauri` 2.12.3 with the `protocol-asset` feature, `tauri-build` 2.7.2, and `tauri-plugin-dialog` 2.8.2. The identifier is `com.zeropulse.pulsecut`. The frontend dev server is Vite on port 1420.

## Consequences

The Linux VM can compile the shell. A Windows installer has not been produced. File dialogs depend on the platform portal. On this VM, `xdg-desktop-portal` was left half-configured by apt, so dialogs are not claimed to work here. Import still has a sample command that does not open a dialog.
