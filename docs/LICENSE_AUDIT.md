### Current distribution stance

- **v0.1.0 does not bundle FFmpeg.** Users install it (Windows: `winget install Gyan.FFmpeg`, which is a GPL build) or point `PULSECUT_FFMPEG_DIR` at a folder containing `ffmpeg` and `ffprobe`. This avoids redistribution obligations until a reproducible FFmpeg build is in place.
- **Planned (Phase 5):** a pinned, reproducibly built FFmpeg (configure flags recorded in `THIRD_PARTY_NOTICES`, source archive published next to each release) placed in `ffmpeg/` next to `PulseCut.exe`, which `FfmpegTools::locate()` already searches first.

## Codec patents

H.264/AAC (and HEVC) are patent-encumbered in some jurisdictions. PulseCut does not implement codecs; it delegates to whatever FFmpeg build the user has. Release notes must state that codec availability and patent licensing depend on the FFmpeg build and the user's jurisdiction. AV1/VP9/Opus export (royalty-free) is a Phase 2 item to give users an unencumbered option.
